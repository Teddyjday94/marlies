# Marlie's Restaurant Website Concept

A clean, dependency-free website concept for Marlie's Restaurant in French Settlement, Louisiana.

## Preview locally

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deploy

The project is static and can be deployed directly to Vercel, Netlify, GitHub Pages, or any standard static host. No build command is required.

## Project files

- `index.html` — semantic content, menu, business information, SEO structured data
- `styles.css` — responsive visual design
- `app.js` — mobile menu, reveal animations, sticky-header enhancement
- `PHOTO-SOURCES.md` — research/image traceability
- `RESEARCH.md` — business research notes
- `tests/test_site.py` — basic content and integration checks

## Ordering

All Order Online calls-to-action point to Marlie's verified DoorDash storefront.
